## A. In-sample exact algebra of true floral-category beta

For each original island i with n≥5 actual Direct carrier species on the SAME named trait endpoint, p_i is its true documented category frequency vector; m_i is the composition reconstructed from its REAL genus weights times the in-REGION observed same-genus distinct accepted-species trait frequency, including focal species; e_i=p_i-m_i. Exactly for any island pair:

    D²(p_i,p_j) = D²(m_i,m_j) + D²(e_i,e_j) + 2 Δm·Δe

The 3 terms reconcile to numerical error <1e−9 for every accepted original pair; a signed interaction may be negative, and **no term is causal or an additive nonnegative fraction of adaptation versus establishment**. The genus reference contains the focal observed plant trait labels, so it is IN-SAMPLE and can become mechanically near-perfect where the original genus has only one directly documented trait state. Its primary scientific utility is as an exact source taxonomic assembly description, not independent explanatory power.

Eligible original pair mask requires identical broad region, geographically DIFFERENT original 10° source blocks, **ZERO SHARED ACCEPTED SPECIES ON THE FULL ORIGINAL botanical island lists** (not just Direct trait carriers), and valid independently mapped geographic coordinates. Pair-equal, island-equal and physical-block-equal additive accounting and leave-one-block deletion all recorded; numeric pair count is NOT biological independent replication.

## B. Stronger test — remove ALL focal island botanical plant species NAMES from potential genus donor training

For each original test island and endpoint, the entire all-status accepted plant species list, including plants without known focal traits, is excluded from ALL candidate Direct source donors **by accepted species name** before creating the source category prior or genus category model. This prevents reusing a species-wide original trait code as its own predictive evidence via another island. The measured original target genus identities and number of documented Direct plants per genus are **known** and drive the oracle predictor, and the donor source STILL uses the same original Direct literature/provenance and is NOT an independently field-measured mainland trait source. Regional donors are distinct same-broad-region original Direct taxa excluding test island names; separately, global same-ledger donors are all original Direct taxa excluding the test island names.

Prediction performance is the observed original island CATEGORY FREQUENCY squared error ||observed−predicted||², compared against the EXACT same out-of-name donor source's **genus-blind** category prior with Jeffreys 0.5 pseudocount/category. Predictive genus frequencies use prespecified shrinkage five prior pseudocounts. **Missing donor genus falls back exactly to the genus-blind prior**; all negative gains remain in the output.

Relative gain below is island-equal mean loss reduction divided by mean same-island genus-blind loss; it is **not percentage of morphological evolution or flora difference explained**. Physical 10° block-equal 999-resample absolute paired loss gain is separately shown and all effects must be interpreted relative to this same-archive conditional test.

## Scientific decision and remaining causal validity

This is most prominent for coarse floral symmetry. Genus-conditional trait predictability differs dramatically between primary whole-flower colour, floral architecture and documented breeding system categories, so a single universal “island floral simplification mechanism” is unsupported.
