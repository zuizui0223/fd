# Measured visitor morphology during cross-site taxon turnover — Chacoff case study

External EMLN26, pinned publisher CSV blobs and original methods (Dryad DOI 10.5061/dryad.8cz8w9gm1). The original study tested morphological/phenological matching, interaction stability and pollen delivery; this separate question concerns similarity of mutually exclusive visitor morphotaxa of the same plant between four 2006 sites. Original data contain species and morphotypes, not universally resolved species. No own biological data, no geography or taxonomic imputation; coordinates have unresolved longitude signs. Only positive finite paired measured mouthpart and body length values. Mouthpart definitions differ by insect order (e.g., beetle mandibles), so morphology is not effective reach.

Frozen before new outcomes: mean absolute log2 length differences across all pairs of exclusive visitor morphotaxa, both components and equal-weight mean. Complete-case binary subweb, >=5 plants and >=5 visitors per site. Same original plant ID, both exclusive sets nonempty. 999 curveball draws with fixed 10n burn and 2n trade attempts per draw, condition on exactly observed shared visitor count (and fixed row/column degrees). Require >=50 accepted and >=20 each half. Equal site pairs within plant, equal plants. Gain = null minus observed distance, positive implies smaller mismatch. Report counts, components, site deletions and >=2 exclusive sensitivity. Descriptive support gate >=10 focal plant taxa, >=3 sites and >=3 site pairs; no p-value or global replication claim from one study. No raw rows exported. No threshold change after outcomes.
