# Measured floral reward as an alternative functional mechanism — 2026-11-27

Scientific owner FD, no protected data in this branch. Previous FD PR81 merged into main (76d874a67d5f528cb1e05f95b6516d603e1440d1); independent publisher traits and negative new-target gate PR80 merged (6c682098b52937f6cbfbfcdb4aa55e64640dae94).

Motivation: longer corolla tubes among tropical island floras could reflect nectar rewards, access constraints, different pollinator morphology, or taxonomic and documentation filtering. A tube-length shift is not a direct measurement of pollinator identity. The plant-only data cannot discriminate these mechanisms.

Public source Keasar & Bodner 2025, DOI 10.1002/ajb2.70125; Zenodo DOI 10.5281/zenodo.17157828 (fixed record). The paper describes nectar sugar production for 973 species and pollen grain count for 1495, plus a morphology dataset (1967 tube-length records and 1583 binary symmetry records). Published counts are not verified harmonized species counts here. The authors' original morphology/reward relationship is not a new result of FD. Fetch exact publisher metadata and file checksums; read only published data, not scripts. Match to already pinned NHM length and Wang conservative symmetry by exact binomial. Do not collapse unknown measurement units or duplicate references into species values before inspecting source documentation. No raw data redistribution. Source read failure will be reported, not silently interpreted as zero ecological overlap.

Prospective novel comparison after schema/coverage check: in the island/mainland same documented species carriers, estimate source-relative measured per-flower/day nectar sugar and per-flower pollen counts separately; compare north/tropical on both geography and source weights. For nectar, distinguish length-associated shift from residual reward differences at fixed radial symmetry and genus, without imputing reward from floral traits. Matched endpoint carriers, no positive-result selection, region and minimum support gates must be fixed before outcome estimates. Pollen is a distinct functional resource, not a formal negative control without assumptions. Roster overlap and reference concentration determine feasibility, and measurement source heterogeneity must be modeled. If coverage fails, no island-scale claim.
