# External floral-syndrome source audit — 2026-11-25

The current fd main explicitly excludes studies using our assembled island flora/trait records, including their aggregates. This new branch starts at the external-only main. It does not modify or merge legacy PR #69; that branch's historic outputs are not independent evidence here.

Sources approved for **metadata and schema/coverage audit only**:

1. Official publisher GIFT v3.1 public API, https://gift.uni-goettingen.de/about and https://biogeomacro.github.io/GIFT/articles/GIFT_API.html. Inspect version, regions, checklist metadata and trait metadata. Do not assume all islands have public, complete native checklists. GIFT region boundaries can aggregate islands; no independent island count until geography and overlapping units are audited. Cite Weigelt et al. (2020) DOI 10.1111/jbi.13623 and Denelle et al. (2023) DOI 10.1111/2041-210x.14213.
2. NHM publisher ADEPT combined.csv resource 2552d157-9519-476c-995d-906e2433cc19, DOI 10.5519/p3dm31kc (CC BY). Download only directly from the publisher URL returned by its public resource metadata. Record byte hash, schema and field-level overlaps. 59,369 species reported by publisher. Extracted flora descriptions may overlap the original literature used in other projects; this is **independent file provenance, not necessarily independent observations**. Flower, petal, corolla-tube and aperture dimensions are distinct. Do not turn a tube length into flower size.
3. Leménager (2024), Dryad DOI 10.5061/dryad.hqbzkh1nh. Antillean Gesneriaceae corolla morphometric study. Metadata preflight only; published README distinguishes confirmed field pollination from morphology-inferred classes. An eventual calibration must exclude inferred labels, use actual measured morphology and distinguish species from individual specimens. Do not use this single-clade study as an island-mainland replication.

No own-project datasets, intermediate exports or names used. This stage does not estimate biological effects or promise that any combination will be feasible. Future study requires independently retrieved source files, immutable hashes, source and measurement schema audit, independently verified checklist native status, geographic nonoverlap, exact accepted-name joins or documented taxonomic concordance, then a frozen pair-specific estimand before scoring. Source overlap prevents a claim of independent biological replication without further checking.
